ClassicalRadio Kodi add-on
===========================

Unofficial community add-on for ClassicalRadio, built on the same AudioAddict architecture as the DI.FM, JazzRadio and RadioTunes community add-ons.

Current version: 0.9.0 (local testing).

Features
--------
- Browse ClassicalRadio channels
- Popular and New views
- Favorites synchronisation
- Premium stream quality selection
- Multiple stream-server fallback
- Dynamic Now Playing metadata
- English and French localisation
- Background metadata updates
- Linux playback-state locking with flock
- Atomic session-cache writes
- Bounded stream probing with conservative fallback
- Redacted stream URLs in debug logs
